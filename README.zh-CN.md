# DeepSeek Harness 远程控制

一个 DeepSeek Harness 插件，用于在两台电脑之间建立远程控制，让一台电脑操作另一台电脑上运行的 DeepSeek Harness 实例。

[English](README.md)

## 使用场景

- 在笔记本上继续使用放在台式机/服务器上的 DSH 会话、文件和工作区。
- 把一台只能通过 Tailscale、SSH 或 WireGuard 访问的机器的 DSH，接到当前浏览器窗口中操作。
- 临时让另一台设备查看或操作本机 DSH，用完立即关闭，不长期开放端口。

两台电脑安装**同一个插件**。被控制的一端打开「本机」页，控制的一端打开「远程」页。

## 工作方式

```
控制端页面
  │  /api、$events 等流量
  ▼
A 侧插件 ── 明文 WebSocket（/bridge，bearer token）──> B 侧插件 ──> B 的 DSH
```

- **本机页（B 侧）**：启动一个带 token 认证的 `/bridge` WebSocket，把本机 DSH 的 RPC、实时流和广播事件转发给已认证的控制端。
- **远程页（A 侧）**：页面 hook 把本窗口的 `/api` 调用和 `$events` 流改道到 bridge；需要本地 Host 参与的设置、附件等仍走本机。
- 两侧使用同一份 JSON 状态记录（预设、开关、文件下载策略、服务时长），状态文件权限为 `0600`。
- 审批/提问在远程连接存在时由远程端回答；最后一个控制端断开后有 10 秒宽限，之后按失败关闭处理。
- 诊断日志默认关闭。只有显式设置 `DSH_REMOTE_CONTROL_TRACE=1` 才会写诊断文件。

## 安全说明与免责声明

**这是完整控制权限的远程控制，不是只读查看器。**

- bridge 使用明文 `ws://` 和 bearer token。token 等价于被控端 Harness 的完整控制权限，包括读取文件、执行高风险操作。只应通过 Tailscale、SSH、WireGuard 等加密隧道使用；不要把 7400（或你选择的端口）暴露到不可信局域网或公网。
- 使用强 token，不要截图、粘贴到公开聊天或提交到仓库；怀疑泄露时立即在「本机」页轮换 token。
- **不建议开启永久服务。** 优先选择 5 分钟到 24 小时的有限时长，用完关闭开关。永久选项也会在 DSH 退出时结束，不是重启后继续运行的服务。
- **文件下载策略不是完整的文件访问边界。** `off` 只让下载键不可用，DSH 的远程预览仍可能通过 RPC 读取文件；`shared`/`home` 只控制下载通道。不要把下载根目录设为 `/`、整个 home 或过宽的共享目录；只授权包含所需文件的最窄目录。
- 不要把 token 交给不受信任的控制端。对方一旦连接，就能以完整控制权限操作本机 DSH。
- 本插件按现状提供，不附带任何担保。网络暴露、token 保管、文件权限以及远程控制端执行的操作由使用者负责。请先在受控环境测试。

## 使用说明

### 本机页（被控制端）

1. 选择一个本机已有的具体 IP（局域网、Tailscale 或其他网卡地址）和 1024 以上端口。
2. 打开开关。端口被占用会报错并保持关闭，不会自动换端口。
3. 首次开启会自动生成 token；复制到控制端。轮换 token 会立即让旧 token 失效并断开旧连接。
4. 按需设置「远程文件下载」策略和服务时长。文件策略只影响下载，不影响预览。

### 远程页（控制端）

1. 填写对端「本机」页显示的地址和 token。
2. 打开开关；页面会刷新一次，之后本窗口的 Remote 调用和实时流走对端。
3. 关闭开关或连接失败时回到本机。连接失败会提示一次，并自动切回本机。

### 保存与预设

- **保存**只记录地址、端口、token 和名称，不绑定端口，也不改变当前连接。
- **开关**才真正应用目标：本机页重新绑定监听；远程页切换传输。
- **选择预设**只把该预设的地址和 token 填回表单，不会自动应用；打开开关才生效。
- 删除当前预设会关闭对应开关；最后一个控制端断开后按宽限规则处理。
- 远程开关和应用每次启动都从关闭开始；本机监听也不会跨 DSH 重启自动恢复。

### 已知限制

- bridge 只支持 `ws://`，不支持 WSS/TLS；需要加密时请使用隧道。
- 远程上传文件不支持。
- 字节 RPC 结果有 64 MB 上限；普通文件下载走 256 KB 分块流，不受这个上限影响。
- 没有远程控制端时，审批/提问只在本机弹；一旦有远程端，只弹远程端（DSH 的一次性 waterfall 限制）。
